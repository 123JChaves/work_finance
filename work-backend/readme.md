# API de controle financeiro em Go

**Para inicializar um projeto em `Go` e criar o arquivo `go.mod`, executar o comando:**
[Comando:] `go mod init <nome-do-modulo>`

**Criar um arquivo local chamado [`go.main`]**

**Para executar o comando em Go:**
[Comando:] `go run main.go`

**Baixar uma biblioteca para criptografar as senhas:**
[Comando:] `go get golang.org/x/crypto@v0.53.0`

**Baixar a biblioteca para criar usar o .env:**
[Comando:] `go get github.com/joho/godotenv`

**Baixar o driver do MySQL:**
[Comando:] `go get github.com/go-sql-driver/mysql`

**Criação do banco de dados:**
[Comando_SQL:] `create database work_finance character set utf8mb4 collate utf8mb4_unicode_ci`

**Para utilizar o ORM do Go [GORM], instalar as dependências:**
[Comando:] `go get -u gorm.io/gorm gorm.io/driver/mysql`
